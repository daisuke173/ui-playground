UI Playground

同じデータを、CSSとJavaScriptを使わず、HTMLの情報構造だけで比較する実験場です。

Data date: 2026-08-27

Theme Switcher

  • Newsroom — 見出し中心。ニュース・読み物向け。
  • Directory — 表中心。大量の項目を比較しやすい。
  • Accordion — details/summaryでセクションを開閉。純HTMLでも操作感がある。
  • Media — 画像・YouTubeサムネイル中心。

方針

  • CSSなし
  • JavaScriptなし
  • 外部フレームワークなし
  • テーマは別HTMLとして保持
  • 各テーマには相互リンクを置き、1クリックで比較可能
